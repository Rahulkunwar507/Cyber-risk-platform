# AI Engine — SIH 2026 Cyber Risk Platform

## What this module does

1. Generates a synthetic cybersecurity dataset for the prototype.
2. Trains a Random Forest model to estimate incident likelihood.
3. Produces feature importance for explainability.
4. Generates prioritized rule-based remediation recommendations.
5. Provides an LLM advisor payload/prompt for human-readable explanations.
6. Returns a clean JSON object that the backend/frontend can consume.

## Important prototype note

The training data is synthetic/simulated because organization-specific historical incident data is not available.
The incident probability is a modeled estimate, NOT a guarantee that an attack will occur.

The LLM does not calculate the numerical risk score. Numerical/model outputs come from deterministic/model components; the LLM is used for explanation and advisory text.

## Run

From the `ai_engine` directory:

```bash
pip install -r requirements.txt
python generate_data.py
python train.py
python main.py
```

To test prediction directly:

```bash
python predict.py
```

## Demo output

The pipeline accepts seven risk features:

- CVSS
- Asset criticality
- Internet exposure
- Exploit availability
- Data sensitivity
- Security control strength
- Patch age

and returns:

- incident probability
- feature importance
- prioritized recommendations
- explanation
- optional risk score / financial exposure passed in by the risk engine

## Backend contract

Send:

```json
{
  "asset": "Customer Database",
  "risk_score": 87,
  "financial_exposure": 5000000,
  "features": {
    "cvss": 9.8,
    "asset_criticality": 10,
    "internet_exposed": 1,
    "exploit_available": 1,
    "data_sensitivity": 10,
    "security_control_strength": 3,
    "patch_age_days": 60
  }
}
```

See `backend_adapter.py`.
